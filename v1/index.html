検索 (?q=)

検索 API: https://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search?q=アスピリン (仕様ページ)

一致した薬を一致度の高い順の配列 (JSON) で返します (打ち間違い・表記ゆれも吸収、limit で件数 1〜100)。各結果に休薬日数・詳細 JSON の URL・参照アプリのページが付き、0 件の時は「もしかして」候補を返します。認証不要・CORS 全開放。Python 標準の urllib から呼ぶ場合は User-Agent を指定してください。

そのほかの方法:

  • 参照アプリの URL 検索: https://numero-uno-jpn.github.io/kyuyaku-data/?q=アスピリン のように開くと検索済みの状態で表示されます (打ち間違い・表記ゆれも吸収)。
  • 手元で検索 (ネットワーク越しに呼ばない): あいまい検索の関数 assets/search.js と索引 search-index.json を使います。 
    import { buildIndex, search } from 'https://numero-uno-jpn.github.io/kyuyaku-data/assets/search.js';
const index = buildIndex((await (await fetch('https://numero-uno-jpn.github.io/kyuyaku-data/v1/search-index.json')).json()).drugs);
search(index, 'アスピリソ');   // → [{ name: 'アスピリン', score: 63, … }]
    (ブラウザ用。Node.js では search.js をダウンロードして import)
