検索 (?q=)

検索 API: https://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search?q=アスピリン (仕様ページ)

一致した薬を 一致度の 高い順の 配列 (JSON) で 返します (打ち間違い・表記ゆれも 吸収、 limit で 件数 1〜100)。 各結果に 休薬日数・詳細 JSON の URL・参照アプリの ページが 付き、 0 件の 時は 「もしかして」 候補を 返します。 認証不要・CORS 全開放。 Python 標準の urllib から 呼ぶ 場合は User-Agent を 指定してください。

そのほかの 方法:

  • 参照アプリの URL 検索: https://numero-uno-jpn.github.io/kyuyaku-data/?q=アスピリン のように 開くと 検索済みの 状態で 表示されます (打ち間違い・表記ゆれも 吸収)。
  • 手元で 検索 (ネットワーク越しに 呼ばない): あいまい検索の 関数 assets/search.js と 索引 search-index.json を 使います。 
    import { buildIndex, search } from 'https://numero-uno-jpn.github.io/kyuyaku-data/assets/search.js';
const index = buildIndex((await (await fetch('https://numero-uno-jpn.github.io/kyuyaku-data/v1/search-index.json')).json()).drugs);
search(index, 'アスピリソ');   // → [{ name: 'アスピリン', score: 63, … }]
    (ブラウザ用。 Node.js では search.js を ダウンロードして import)
