検索 API 仕様

薬の名前で 検索し、 一致した薬を 一致度の 高い順の 配列 (JSON) で 返す API です。 一般名・別名・商品名・後発品名・薬効分類名で 検索でき、 打ち間違いや 表記ゆれも 吸収します。 検索の 仕組みは 参照アプリ と 同じです。 認証・登録は 不要で、 無料で 使えます。

GEThttps://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search?q=薬の名前

1. 試してみる

「検索する」を 押すと、 実際の API の 応答が ここに 表示されます。

2. リクエスト

パラメータ必須説明
q必須検索語 (100 文字以内)。 URL エンコードして 渡す。 一般名・別名・商品名・後発品名・薬効分類名 (例: DOAC) のどれでも、 一部だけでも可。 ひらがな・半角カナ・英字も 可
limit任意返す 最大件数。 1〜100、 既定 20
  • メソッドは GET のみ (OPTIONS は CORS の 事前確認用)。
  • CORS は 全開放 (Access-Control-Allow-Origin: *)。 ブラウザの JavaScript から 直接 呼べます。

3. レスポンス

Content-Type: application/json; charset=utf-8。 例 (q=エンレスト、 一部省略):

{
  "query": "エンレスト",
  "count": 2,
  "results": [
    {
      "name": "バルサルタン",
      "category": "ARB (降圧薬)",
      "score": 90,
      "kind": "prefix",
      "matched": "エンレスト錠50mg",
      "surgery_high_risk_days_before": 1,
      "surgery_low_risk_days_before": 0,
      "contrast_required": false,
      "contrast_days_before": null,
      "detail": "https://numero-uno-jpn.github.io/kyuyaku-data/v1/drugs/バルサルタン.json",
      "page": "https://numero-uno-jpn.github.io/kyuyaku-data/#/drugs/バルサルタン"
    },
    { "name": "サクビトリル・バルサルタン", … }
  ],
  "suggestions": [],
  "_notice": {
    "license": "CC BY 4.0",
    "license_url": "https://creativecommons.org/licenses/by/4.0/",
    "license_exceptions": "quote_excerpt / quote_translation_excerpt は CC BY 4.0 の 対象外 …",
    "attribution": "梅谷 直亨, 休薬情報データベース (Kyuyaku Data), https://github.com/numero-uno-jpn/kyuyaku-data",
    "disclaimer": "本データは 意思決定支援のための 参考情報です。 …"
  }
}

トップレベル

項目型説明
query文字列受け付けた 検索語 (前後の 空白は 除去)
count数値results の 件数
results配列一致した薬。 一致度 (score) の 高い順。 一致なしなら 空配列
suggestions配列一致なしの 時のみ、 「もしかして」 の 候補 (最大 3 件)。 各要素は name (一般名)・term (近い名前)・distance (違う文字数)
_noticeオブジェクトライセンス・帰属表示・免責

results[] の 各要素

項目型説明
name文字列一般名 (この データベースでの 薬の 名前)
category文字列薬効分類
score数値一致度 (40〜100)。 下表 参照
kind文字列一致の 種類。 下表 参照
matched文字列 / null一致した 名前 (商品名など)。 薬効分類で 一致した 場合は null
surgery_high_risk_days_before数値 / null出血リスクの 高い 手術・処置の 前の 休薬日数 (安全側の値)。 0 は 休薬不要、 null は 記載なし
surgery_low_risk_days_before数値 / null出血リスクの 低い 手術・処置の 前の 休薬日数 (同上)
contrast_required真偽 / null造影 CT 前の 休薬が 必要か
contrast_days_before数値 / null造影 CT 前の 休薬日数
detail文字列その薬の 詳細 JSON (ガイドライン別の値・根拠・出典) の URL
page文字列参照アプリの その薬の ページの URL

休薬日数は、 現行版の ガイドラインの 最長値 (安全側)、 記載が なければ PMDA 添付文書の 値です。 ガイドラインごとの 値・値の出どころ・根拠は detail の JSON で 確認してください。

4. 一致の 種類と 得点

kindscore意味例 (検索語 → 一致)
exact100名前と 完全に 一致アスピリン → アスピリン
prefix90名前の 先頭と 一致ばいあすぴりん → バイアスピリン錠100mg
partial80名前の 一部と 一致ピドグレル → クロピドグレル
variant70長音・濁点などの 表記ゆれを 吸収して 一致リバロキサバン → リバーロキサバン
category66薬効分類名と 一致DOAC → アピキサバン ほか
typo40〜65打ち間違いを 補って 一致 (4 文字以上で 1 文字、 8 文字以上で 2 文字まで)アスピリソ → アスピリン

比較の 前に、 全角/半角・ひらがな/カタカナ・小書き文字 (ュ/ユ)・大文字/小文字・空白の 違いは すべて 吸収します。 同じ得点の 場合は 名前の 短い順です。

5. エラー

状態HTTP応答
q が ない・空400{"error": "q is required", "usage": …}
q が 100 文字超400{"error": "q is too long (max 100 chars)"}
GET 以外の メソッド405{"error": "Method not allowed (GET only)"}
存在しない パス404{"error": "unknown endpoint", …}
データの 取得に 一時的に 失敗503{"error": "data unavailable"} (Retry-After: 60)

一致が 0 件の 場合は エラーでは なく、 200 で count: 0・空の results・suggestions を 返します。

6. コード例

curl

curl -G https://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search --data-urlencode "q=エンレスト"

JavaScript (ブラウザ / Node.js)

const url = new URL('https://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search');
url.searchParams.set('q', 'エリキュース');
const { results } = await (await fetch(url)).json();
for (const r of results) {
  console.log(r.name, r.surgery_high_risk_days_before, r.surgery_low_risk_days_before);
}
// → アピキサバン 3 1

Python (requests)

import requests
r = requests.get('https://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search', params={'q': 'アスピリン'})
print(r.json()['results'][0]['name'])   # アスピリン

Python (標準ライブラリ urllib)

urllib では User-Agent を 必ず 指定してください。 既定の Python-urllib/… は 配信基盤 (Cloudflare) の 仕組みで 拒否されます (HTTP 403、 error code 1010)。

import json, urllib.parse, urllib.request
url = 'https://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search?' + urllib.parse.urlencode({'q': 'アスピリン'})
req = urllib.request.Request(url, headers={'User-Agent': 'my-app/1.0'})
print(json.load(urllib.request.urlopen(req))['results'][0]['name'])   # アスピリン

検索結果から 詳細を 取得する

const { results } = await (await fetch('https://kyuyaku-data.numero-uno-jpn.workers.dev/v1/search?q=' + encodeURIComponent('プラビックス'))).json();
const { drug } = await (await fetch(results[0].detail)).json();
console.log(drug.guideline_variations.surgery);   // ガイドライン別の値・値の出どころ・根拠

7. データの 鮮度・キャッシュ・利用上の 注意

  • データは 静的 API (GitHub Pages) と 同じものを、 最大 10 分の 遅れで 反映します。 データの版は v1/meta.json の data_version で 確認できます。
  • 検索結果の 応答は Cache-Control: public, max-age=300 (5 分) です。
  • 無料の 配信基盤 (Cloudflare Workers) で 運用しています。 全体で 1 日 10 万件程度が 目安です。 大量に 使う 場合は、 全件データ を 取り込むか、 手元で 動く 同じ 検索 (assets/search.js と v1/search-index.json) を 使ってください。
  • 予告なく 仕様を 変える ことは しない 方針ですが、 無保証です。 変更する 場合は GitHub で お知らせします。
  • 本データは 意思決定支援のための 参考情報です。 最終的な 休薬判断は 医療者の 責任で 行ってください (免責事項)。
