参照アプリの 使い方

この参照アプリでは、 手術・処置の前や 造影 CT 検査の前に 休薬が 必要な 薬について、 学会ガイドラインや PMDA 添付文書などの 一次資料に基づく 情報を 調べられます。 登録・ログインは 不要で、 スマートフォンでも 使えます。

目次
  1. 薬を 探す
  2. 薬効分類で 絞り込む
  3. 一覧の 見方
  4. 薬の 詳細ページ
  5. ガイドライン別の値と 根拠

1. 薬を 探す

画面上部の 検索欄に 薬の名前を 入力すると、 入力するそばから 一覧が 絞り込まれます。

  • 一般名・商品名・別名・後発品名の どれでも 検索できます (例: 「エリキュース」 で アピキサバンが 出ます)。
  • 名前の 一部だけでも 検索できます。
  • ひらがな・半角カナ・英字でも 検索できます (例: 「えりきゅーす」「apixaban」)。
  • 多少の 打ち間違いや 表記ゆれでも 見つかります (例: 「アスピリソ」→ アスピリン、 「リバロキサバン」→ リバーロキサバン、 「プラビクス」→ クロピドグレル)。 長音 (ー) の 有無や 濁点の 違いも 吸収します。
  • 結果は 一致度の 高い順に 並びます。 商品名で 一致した場合は 「○○ に一致」、 打ち間違いを 補って 見つけた場合は 「○○ に近い名前」 と 表示されます。 配合剤などで 1 つの 商品名が 複数の 薬に 当たる場合は、 すべて 表示されます。
  • 「DOAC」「SGLT2」 のように 薬効分類の 名前でも 検索できます。

見つからない ときは 「もしかして」

何も 当たらない 場合は、 近い 名前の 候補を 「もしかして」 として 表示します。 候補を 押すと、 その名前で 検索し直します。

URL で 検索する

https://numero-uno-jpn.github.io/kyuyaku-data/?q=アスピリン のように URL の 末尾に ?q=薬の名前 を 付けて 開くと、 検索済みの 状態で 表示されます。 検索欄に 入力すると、 アドレス欄の URL も 自動で 変わるので、 そのまま 共有や ブックマークに 使えます。

2. 薬効分類で 絞り込む

検索欄の下の ボタン (抗血栓薬、 糖尿病薬、 降圧・利尿薬 など) を 押すと、 その分類の 薬だけが 表示されます。 もう一度 押すか 「すべて」 を 押すと 解除されます。 検索欄と 組み合わせることもできます。

3. 一覧の 見方

カードには 薬の 一般名・分類と、 休薬日数の バッジが 表示されます。

  • 周術期(高) 3 日 出血リスクの 高い 手術・処置の 前の 休薬日数
  • 周術期(低) 1 日 出血リスクの 低い 手術・処置の 前の 休薬日数
  • 造影CT 2 日 造影 CT 検査の 前の 休薬
  • 「休薬不要」 は 休薬の 必要がない (継続してよい) という 意味、 「休薬 記載なし」 は 休薬の 記載が ない 薬です。

ここに 表示される 日数は、 現行版の ガイドラインの 中で いちばん長い 値 (安全側) です。 ガイドラインに 記載が なければ PMDA 添付文書の 値を 使います。

4. 薬の 詳細ページ

カードを 押すと、 その薬の 詳細ページが 開きます。 ブラウザの 「戻る」 で 一覧に 戻れます (絞り込みは そのまま 残ります)。

  • 休薬日数を 大きく 表示します (一覧と 同じ 安全側の値)。
  • 補足 (黄色の欄) に、 用量・腎機能による 違いや、 ガイドライン改訂の 要点などを 記載しています。
  • 高リスク / 低リスク手術の例を 載せています。 出血リスクの 分類は ガイドラインごとに 異なるので、 目安として ご覧ください。

5. ガイドライン別の値と 根拠

「ガイドライン別」 の 表には、 資料ごとの 休薬日数が 並びます。 資料によって 値が 違う ことが 一目で 分かります。

  • 出典名を 押すと、 一次資料 (PDF は 該当頁) が 新しいタブで 開きます。
  • 値の出どころのラベル:
    • 直接記載 ガイドラインが その薬の 値を 直接 書いている
    • クラス推奨 ガイドラインは 「SGLT2 阻害薬」 のように 薬の 種類 単位で 推奨しており、 その値を この薬に 当てはめた
    • 計算値 ガイドラインの 「半減期の N 倍」 などの ルールから 計算した値
    「直接記載」 以外は、 ガイドラインに この薬の 日数が 明記されているわけでは ありません。
  • 備考に、 用量別・腎機能別などの 条件を 要約しています。
  • 「根拠 (引用または抜粋) と 所在」を 押すと、 一次資料からの 引用または抜粋と、 資料の どこに 書かれているか (頁・表) が 表示されます。 長いものは 抜粋 (「 … 」 は 中略) で、 一部に 参考資料・作者による 注記を 含みます。 正確な 記載は 原典で 確認してください。

6. 出典

ページの 下部に、 その薬の 出典 (ガイドライン・添付文書・文献) を 一覧で 載せています。 リンクは 新しいタブで 開きます。 「根拠」 を 開くと、 引用または抜粋・英文の 和訳・所在が 表示されます。

7. コピー・共有

  • 内容をコピー: 薬の名前・休薬日数・補足・ガイドライン別の値・出典を テキストで コピーします。 カルテや 院内の 資料に 貼り付けるときに 便利です (末尾に 出典の 表示が 付きます)。
  • リンクをコピー: その薬の ページの URL を コピーします。 URL を 開くと 直接 その薬の ページが 表示されるので、 共有や ブックマーク、 スライドへの 掲載に 使えます。

8. スマートフォンで 使う

スマートフォンの ブラウザでも 同じように 使えます。 ホーム画面に 追加しておくと、 すぐに 開けます。 端末が ダークモードの 場合は 暗い配色で 表示されます。

9. 使うときの 注意

  • このアプリの 情報は 意思決定を 支援するための 参考情報 です。 休薬・再開の 最終判断は、 患者の状態・手術の内容・血栓と出血の リスクを 踏まえて 担当の 医療者が 行ってください。
  • 冠動脈ステント留置後の 抗血小板薬など、 休薬しないことが 推奨される 場合が あります。 日数だけで 判断せず、 補足と ガイドラインの 推奨文を 確認してください。
  • ガイドラインや 添付文書の 改訂から 反映までに 時間差が あることが あります。 データの版と 更新日は ページ下部に 表示しています。
  • 誤りに 気づいた 場合は、 誤りの報告(新しいタブで開く) から、 根拠となる 資料と 頁を 添えて お知らせください。
