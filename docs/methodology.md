# データの作り方 (詳細)

休薬情報データベース (Kyuyaku Data) の 値が どのように 作られ、 どう 誤りを 防いでいるかを 詳しく 説明します。 概要は [README の「データの作り方」](../README.md#データの作り方) を ご覧ください。

- 対象読者: このデータを 使う・評価する 医療者、 研究者、 論文・学会発表の 査読者
- 記載時点: データ版 0.8.6 (2026-10-25 更新)。 件数は この版の [`data/washout_public_v1.json`](../data/washout_public_v1.json) から 集計しています
- この文書で 扱わないもの: AI への 指示文、 AI サービスの 契約・運用の 設定 (公開していない 理由は [README](../README.md#このリポジトリで-公開しているものしていないもの) を 参照)

## 1. 基本方針

### 1.1 根拠に するのは 一次資料の 原文だけ

休薬日数の 根拠には、 **一次資料の 原文を 実際に 読んで 確かめた 記載だけ** を 使います。 次のものは 根拠に しません。

- 要約、 検索結果、 二次的な 解説記事
- AI の 記憶や、 AI が 作った 評価レポート (修正の 候補を 知る きっかけには 使うが、 確定は 原文との 照合の 後)

### 1.2 一次資料として 扱う 範囲

| 区分 | 資料 | 扱い |
|---|---|---|
| 一次資料 | 国内の 添付文書 (PMDA)、 海外の 添付文書 (FDA)、 学会・公的機関の 正式な ガイドライン | 原文と 照合できれば 「確認済み (`verified`)」 に できる |
| 補助資料 | 専門家の 合意文書、 実務向けの ハンドブック、 関連資料 | 判断の 参考には するが、 確認状況は 「補助的な 参照先 (`helper_link`)」 に とどめる |
| 採用しない | 一施設の 院内規約、 ガイドラインと 紛らわしい 解説記事、 実在が 確認できない 資料 | 出典に 載せない |

「公開されている」 ことは、 一次資料として 扱う 理由に なりません。

### 1.3 ガイドライン間の 違いは 併記する

同じ 薬でも、 ガイドラインによって 推奨される 休薬日数は 大きく 異なります。 多くは 誤りではなく、 **想定している 手技・目的・患者の 違い** に よるものです。

| 違いの 例 | 主な 理由 |
|---|---|
| 区域麻酔・神経ブロック と 内視鏡 | 避けたい 合併症が 違う (脊髄硬膜外血腫 と 処置後の 出血) |
| 区域麻酔 と 一般手術 | 想定する 手技と 出血の 重さが 違う |
| 周術期 と 冠動脈インターベンション後 | 出血の 予防 と ステント血栓症の 予防の どちらを 重く 見るか |
| 海外 と 国内 | エビデンスに 基づく 最小値 と、 安全側の 慣習 |

このため、 **片方の 値だけを 採ることは せず、 すべての ガイドラインの 値を 並べて 記録** します (`guideline_variations`)。 一覧で 大きく 表示する 値は、 そのうちの 安全側 (長い方) です ([5.1](#51-表示用の-値-安全側))。

### 1.4 見落としを 減らすことを 優先する

休薬の 確認で 怖いのは 「必要な 休薬を 見落とす」 ことです。 迷う 場合は 安全側 (長い方) の 値を 表示し、 より 厳しい 記載が ある 資料は 隠さずに 並べます。 個々の 患者に 合わせた 判断は、 ガイドラインごとの 値と 条件を 見て 医療者が 行う 前提です。

## 2. 一次資料の 収集と 保管

- 参照する ガイドライン・添付文書は、 **原典の PDF を 取得して 保管** し、 取得元の URL を 記録します。 改訂の 監視対象に 登録した 資料は、 内容の ハッシュ値も 記録します。 学会サイトの URL は 改訂や サイトの 移転で 変わることが あり、 原典を 手元に 残しておけば、 URL が 変わっても 引用を 確かめ直せます。
- 監視対象の PDF は、 毎月 公開元から 取得して 改訂の 有無を 確認します ([9](#9-変化の-検知と-反映))。 2026-10 時点の 監視対象は、 ガイドライン PDF 33 本と 添付文書 PDF 118 件です。
  - 公開元が 自動取得を 拒否する ガイドライン (ACC/AHA 2024) は、 毎月の 承認ページで 手動の 確認を 求めます。
  - 発行から 3 年以上 経った 資料は、 それ以上の 静かな 改訂は ないものと 扱います (新版は 別の 資料として 扱う)。
  - 出典に 使っていない 資料・入口ページ・書籍の 抜粋 (ガイドライン 7 本) と、 収載対象外・販売中止の 添付文書は 監視していません。
- 原典の PDF は 各学会・製薬企業の 著作物なので、 このリポジトリでは 公開していません。 各出典の `url` / `source_url` から 原典を 参照できます。

## 3. ガイドラインからの 抽出

新しい ガイドライン (または 改訂版) は、 次の 手順で 構造化データに します。

### 3.1 関係する 頁の 絞り込み

数十〜数百頁の ガイドラインでは、 まず AI が 周術期の 休薬に 関わる 頁を 探し、 前後 1 頁を 含めて 対象を 絞ります。 絞り込んだ 後も **元の PDF の 頁番号と 対応付けて 扱い**、 記録する 所在 (頁) が ずれないように します。 関係する 頁を 特定できない 場合は、 推測で 進めずに 作業を 止めます。

### 3.2 2 通りの 読み方で 独立に 抽出

同じ ガイドラインを、 **異なる 指示文で 2 回、 互いの 結果を 見せずに** 抽出します。 長い 文書では、 必要に 応じて 片方を 章ごとに 分けて 読む 抽出に します。 AI には 文字だけでなく、 表や 図を 含む 原本の 頁を そのまま 渡します。

抽出する 項目 (薬ごと):

| 項目 | 内容 |
|---|---|
| 休薬日数 | リスク 高 / 低 の 手術ごと (時間で 書かれていれば 時間も) |
| 条件 | 用量別・腎機能別 などの 場合分け |
| 再開 | カテーテル抜去後の 再開時期 などが あれば |
| 所在 | 頁・表番号・項目番号 |
| 引用 | 原文 そのままの 記載 |

### 3.3 食い違いを 原文で 裁定

1. 2 つの 抽出結果の 違いを AI が 一覧に します
2. 違いに 関わる 頁だけを 原典の PDF から 切り出します
3. AI が その 頁の 原文を もう一度 読んで、 どちらが 正しいかを 判定し、 最終的な 結果を 作ります (原典が 指定されていない 場合は 裁定しません)
4. 判定の 経緯 (一致した 項目、 食い違った 項目と その 根拠) を 記録として 残します

片方の 読み方だけで 生じた 思い込みは、 この 段階で もう片方との 食い違いとして 表に 出ます。

### 3.4 形式の 検査と 作者の 確認

- 最終結果が 決められた 形式 (スキーマ) に 合わなければ、 最終版として 採用しません。 公開前の 検査でも、 すべての ガイドラインの 最終結果を 形式の 検査に かけます ([8](#8-誤りを-入れない-自動の-検査))。
- AI が 作った 結果は 「未確認」 として 扱い、 **作者が 原文と 照合して 確認するまで 公開データには 反映しません**。 表の 行・列や 推奨の 項目番号は、 PDF を 画像に して 目で 確かめます。

## 4. 添付文書の 扱い

### 4.1 添付文書に 書かれている こと

周術期の 休薬について、 添付文書の 多くは 「手術前後は インスリンによる 血糖管理が 望ましい」「手術前は 投与を 中断する」 のような **薬効クラス単位の 定性的な 記載** に とどまり、 具体的な 日数が 書かれているのは 抗血小板薬・抗凝固薬・一部の ホルモン製剤などに 限られます。 生物学的製剤・抗リウマチ薬の 多くは、 添付文書に 周術期の 休薬の 記載が なく、 学会ガイドラインが 根拠に なります。

### 4.2 原文の 取り出し方

- 添付文書は 2 段組の PDF が 多く、 文字として 取り出すと 左右の 段が 混ざることが あります。 段組みを 認識できる 方法で 読み取り、 混線が ないかを 自動で 検査します ([8](#8-誤りを-入れない-自動の-検査))。
- 禁忌などの 項目番号は、 文字の 取り出し方に よって ずれることが あるため、 PDF を 画像に して 目で 確認します。
- 確認状況を 引き上げる 際は、 引用を 原文から 切り出して 照合します。 出典欄の 引用には、 表の 内容を 書き起こした ものや 要約を 含む ものが あります。 変更の たびに 自動で 照合しているのは、 ガイドラインから 抽出した データの 引用です ([8](#8-誤りを-入れない-自動の-検査))。

### 4.3 「添付文書由来」 と 書く 条件

日数を 「PMDA 添付文書」 の 値として 記録するのは、 **その 日数が 添付文書の 本文に 実際に 書かれている 場合だけ** です。 添付文書に 日数が なく、 ほかの 資料から 日数を 採った 場合は、 その 資料を 出典に します。 国内の 添付文書に 日数が ない 薬で、 FDA の 添付文書に 記載が ある 場合は、 FDA の 添付文書を 出典に することが あります。

## 5. 値の 決め方

### 5.1 表示用の 値 (安全側)

一覧や 参照アプリで 大きく 表示する `display_*` は、 次の 順で 決めます。

1. **現行版の ガイドラインの 値の 最大値** — 同じ ガイドラインの 旧版は 除外 (版は `version_label` / `version_year` で 区別。 80 件の 値に 版を 記録)
2. ガイドラインに 記載が なければ、 **PMDA 添付文書の 値の 最大値**
3. どちらも なければ、 **作者の 採用値** (`high_risk_days_before` 等。 手術当日の休薬は `high_risk_day_of` 等が `true`)

旧版の 値は 履歴として 残しますが、 表示用の 値の 計算には 使いません。 改訂で 値が 変わった ことを 追えるように するためです。

例: アピキサバン (周術期)

| 出典 | 高リスク手術 | 低リスク手術 |
|---|---|---|
| JSA・JSRA・JSPC 2026 改訂第 2 版 | 3 日 | 0 日 |
| ACC/AHA 2024 | 2 日 | 1 日 |
| PMDA 添付文書 | 2 日 | 1 日 |
| **表示用の 値** | **3 日** | **1 日** |

### 5.2 値の 出どころ (`value_derivation`)

ガイドライン別の 値 397 件の 内訳です。

| 値 | 件数 | 意味 |
|---|---|---|
| `direct` | 241 | ガイドラインが その 薬の 値を 直接 記載 |
| `class` | 36 | ガイドラインは 薬効クラス (例: SGLT2 阻害薬) 単位で 推奨。 その 値を 個々の 薬に 当てはめた |
| `derived` | 11 | ガイドラインの 「半減期の N 倍」 などの ルールから 作者が 計算した |
| (なし) | 109 | 未分類 (PMDA 添付文書などの 手入力値) |

`direct` 以外は、 ガイドラインに その 薬の 日数が 明記されているわけでは ありません。 利用する 際は この 区別を 確認してください。

### 5.3 用量・腎機能による 違い

用量や 腎機能で 休薬期間が 変わる 場合 (例: DOAC の 腎機能別、 用量別の 推奨)、 数値の 欄 (`high_risk_days` 等) には 安全側の 値を 入れ、 場合分けの 内容を `dose_dependent_summary` に 記録します (397 件中 136 件)。

### 5.4 日数の 表し方

- 単位は 日です。 `0` は 休薬不要、 `null` は 記載なし です。
- 原文が 時間で 書かれた 推奨 (例: 「48 時間前」) は、 時間のまま (`*_hours`) 記録します。 アプリと 表示推奨値 (`display_*`) では 日数に 切り上げます (12 時間 → 1 日、 48 時間 → 2 日)。 手術時刻は 当日 動くことが あるため、 前日から 休薬する 扱いに しています。 原文の 時間は アプリの 説明と `dose_dependent_summary` (例: 「2日 (48時間)」) で 確認できます。
- 原文が 「手術当日の休薬」 (当日の朝から中止、 on the day of surgery) の 推奨は、 日数ではなく 当日休薬の 印 (`*_day_of: true`、 日数は `null`) で 記録し、 アプリでは 「当日休薬」 と 表示します。 `1` 日と 書くと 前日からの休薬、 `0` と 書くと 継続と 誤解される ためです。 比べる ときは 0 日より 長く 1 日より 短い ものとして 扱います。

### 5.5 根拠が あいまいな 値の 扱い (作者解釈)

手術の ガイドラインに 記載が なく、 別の 場面 (内視鏡・区域麻酔) の 値や 薬効クラスの 記述、 類薬の 添付文書が 日数の 由来に なっている 薬が あります。 たとえば リマプロストの 1 日は、 消化器内視鏡ガイドライン (2012) の 「チエノピリジン誘導体以外の 抗血小板薬は 1 日」 という クラス単位の 推奨 (同ガイドライン自身が 明確な エビデンスは ないと している) だけが 由来でした。

こうした 薬 (2026-10 時点で 20 剤) は、 原典と 添付文書を 読み直し、 作者解釈を データとして 記録しています。 原典の 引用 (`quote_excerpt`) とは 別の 項目で、 原典の 記述では ありません。

- `surgery.author_interpretation`: 薬全体の 解釈 (日数が どの 資料の どの 記述から 来たか、 根拠の 弱さ など)
- `references[].author_interpretation`: 出典ごとの 解釈。 区分 `context` (手術・区域麻酔・内視鏡・添付文書・その他)、 `mention` (薬剤名の 有無: 薬剤名 / なし)、 `recommendation` (休薬の 推奨の 単位: 薬剤名 / クラス / なし) と、 説明の 文 `text`。 `recommendation` が 「なし」 の 出典は、 確認したが 休薬の 記載が なかった 資料で、 休薬の 根拠では ありません

値は 次の 原則で 決めています。

1. **手術・区域麻酔の 資料が 何も ない 薬は、 日数を 空 (記載なし) に する。** 別の 場面の 値を 当てはめた 数字は、 思い込みを 広める おそれが あるため 出しません (リマプロスト、 オメガ3脂肪酸エチル、 ベラプロスト)。
2. **資料が 「原則継続、 条件付きで 休薬」 と する 薬は、 高リスクに 条件付きの 目安、 低リスクに 継続 (0) を 入れる。** 例: JSA 改訂第 2 版 (p.24) は イコサペント酸エチル・シロスタゾール・ジピリダモール・ハーブ類・抗うつ薬を 「休薬は必須でない」 と したうえで、 出血リスクが 高い 事例で 休薬する 場合の 目安 (7・2・2 日 など) を 示しており、 この 目安を 高リスクの 欄に 入れています。
3. **添付文書が 日数なしで 休薬を 求める 薬は 1 日。** 類薬・別の 場面の 値 (例: バゼドキシフェンに ラロキシフェンの 3 日、 シロリムスに 肺移植前の 2 週) は 使わず、 補足に 参考として 残します。 ただし 休薬の 理由が 「手術で 食事が とれない こと」 の 指示 (経口血糖降下薬の 「手術前後は 禁忌・ 不適」) は、 絶食が 始まる 手術当日の 休薬 (当日休薬) と します (メトホルミン、 ピオグリタゾン、 イメグリミン、 DPP-4 阻害薬)。
4. **投与間隔が 1 週以上の 製剤 (注射・内服を 問わない) は、 日数なしの 休薬指示に 日数を 当てない (「高リスク 日数なし」)。** 3 の 1 日は 毎日 服用する 薬を 前提に した もので、 週 1 回以上の 間隔の 製剤では 意味を 持たないため。 手術の 日程は 投与の スケジュールに 合わせて 処方医と 決める (マルスタシマブ、 トレラグリプチン、 オマリグリプチン)。
5. **ガイドラインの 「半減期の N 倍」 で 計算する 値には、 ガイドラインが 書いた 半減期を 使う。 ただし それが 添付文書の 記載の 範囲から 外れる ときは、 添付文書の 代表値 (母集団解析の 値が あれば その値) を 使う。** 計算するのは 作者なので、 薬の 性質を 表す 数値は 一次資料の 添付文書と 食い違わないように する (リサンキズマブ: JDA の 「約 11 日」 は 添付文書の 約 27〜33 日 と 合わないため 28 日 × 4 = 112 日)。
6. **半減期の 5 倍が 2 か月を 超える 生物学的製剤は、 長い 休薬に よる 再燃の 警告を 補足に 書く。** 高リスクの 値は ガイドラインの 記載 (半減期の 3〜5 倍) の まま 変えません。 BSR 2019 が アダリムマブ・ アバタセプトに ついて、 この 長さの 休薬は 病勢の 大きな 悪化・ 再燃を 招きうると 警告して いるためです (アダリムマブ、 ゴリムマブ、 セルトリズマブ ペゴル、 アバタセプト、 ウステキヌマブ、 セクキヌマブ、 イキセキズマブ、 リサンキズマブ、 グセルクマブ)。

また、 原文が 出血リスクの 区分なしに 範囲 (例: 「5〜7 日」) で 書かれている 場合は、 上限を 高リスクに 当て、 低リスクは 空 (記載なし) に します。 「休薬する 場合は N 日」 と 条件付きで 一つの 日数を 示す 場合 (ESC 2022 の P2Y12 阻害薬) も 同じです。 原文が 低リスクの 手術に ついて 何も 書いていない ためです。

## 6. 根拠の 確認状況

出典ごとに、 確認の 深さを 4 段階で 記録します (`references[].verification_status`)。

| 値 | 件数 | 条件 |
|---|---|---|
| `verified` | 265 | 一次資料 ([1.2](#12-一次資料として-扱う-範囲)) の 本文を 読み、 原文と 照合したうえで、 所在 (頁・表) と 引用または抜粋を 記録した |
| `helper_link` | 185 | 補助的な 参照先 (専門家の 合意文書・関連資料など)。 日数の 根拠としての 確認は していない |
| `landing_only` | 81 | 資料の 入口ページへの リンク。 該当箇所までは 特定していない |
| `unverified` | 19 | 未確認 |

- 157 剤 中 147 剤に、 `verified` の 出典が 1 件以上 あります。
- `verified` に する 際は、 AI が 原文を 読んで 示した 根拠を **作者が 原文で 確認する** 方針です。
- 根拠の ない 日数を、 出典を 追加する だけで 「確認済み」 に 見せることは しません。 専門家の 合意文書を 追加しても、 確認状況は 上げません。

## 7. 引用または抜粋の 扱い

- 根拠の 透明性のため、 出典ごとに 一次資料からの 引用または抜粋 (`quote_excerpt`) を 載せています。 英文には 和訳 (`quote_translation_excerpt`、 80 件) を 付けています。
- ガイドラインから 抽出した データの 引用は、 変更の たびに 原文と 機械的に 照合しています ([8](#8-誤りを-入れない-自動の-検査))。 出典欄の 引用には、 表の 内容の 書き起こしや 要約を 含む ものが あります。 和文 300 字 / 英文 600 字を 超えるものは 抜粋し、 ` … ` は 中略を 表します。 一部、 参考資料・作者による 注記を 含みます。
- 引用は 著作権法 32 条に 基づく もので、 著作権は 各権利者に 帰属し、 CC BY 4.0 の 対象外です ([NOTICE.md](../NOTICE.md))。
- 正確な 記載は、 所在 (`location_in_source` / `source_location`) と URL (PDF は 該当頁に 移動) から 原典で 確認してください。

## 8. 誤りを 入れない 自動の 検査

データを 変更する たびに、 次の 検査を 自動で 行います。 公開データ・API・参照アプリへの 同期と 本番への 配置は、 これらの 検査に **すべて 合格した 場合だけ** 行い、 **一つでも 不合格なら 反映しません**。 コミットの 前にも 同じ 検査を 実行します。

| 検査 | 何を 見るか | 防ぎたい 誤り |
|---|---|---|
| 引用の 実在検査 | ガイドラインから 抽出した 引用が、 一次資料から 取り出した 本文に 文字どおり 存在するか | AI が もっともらしい 引用を 作る (ハルシネーション) |
| 数値の 逆照合 | ガイドラインから 抽出した 休薬日数などの 数値が、 その 薬の 引用の 中、 または 原文で その 薬の 名前の 近く (200 字以内) に 現れるか。 数字の 区切り (「17 日」 に 「7 日」 を 一致させない) と、 日・週・月・時間の 換算を 考慮する。 自動で 一致した 値も 含め、 すべての 値に 作者が 原文を 読んで 根拠を 記録した ものだけを 通し、 記録の ない 値が 出たら 失敗に する (休薬不要の `0` と 当日休薬の 印も 対象)。 ガイドラインに 書かれていない 外部の 値は、 記録が あっても 失敗に する | 原文に ない 数値の 混入、 別の 薬・別の 文脈の 数値の 取り違え |
| 値の 回帰検知 | 全薬剤・全ガイドラインの 値を 記録した 基準と 突き合わせ、 値の 変化を 検出。 意図した 変更は 作者が 明示的に 承認して 基準を 更新する (承認しなければ コミットも 反映も できない) | ある 箇所の 修正が、 関係ない 薬の 値を 変えてしまう、 値の 取り違え |
| 別名の 衝突検知 | 1 つの 薬に、 同じ ガイドラインの 値の 異なる 項目が 複数 当たらないか | 似た 名前の 薬 (例: 同じ 成分の 経口薬と 注射薬) の 値の 取り違え |
| 添付文書の 抽出崩れ検知 | 2 段組 PDF の 読み取りで 起きる 文字の 混線が ないか | 判読できない 引用の 混入 |
| 公開データの 検査 | 内部用の 項目の 混入、 引用の 長さの 上限、 公開データが 正本と 一致しているか | 公開物と 正本の ずれ |
| 形式の 検査 | ガイドラインからの 抽出結果 (最終版) が 決められた 形式 (スキーマ) に 合っているか | 項目の 欠落・型の 誤り |
| 単体テスト | 検索・表示などの 処理が 壊れていないか | 処理の 不具合 |

原文の 文字を 取り出せない 資料 (画像の PDF など) の 引用と 数値は、 自動では 照合できず 警告に とどまります (2026-10 時点 引用 7 件)。 ガイドラインから 抽出した 数値は、 自動の 照合で 一致した ものも 含めて 全件 (2026-10 時点 703 件)、 作者が 原文 (表は PDF の 画像) を 読んで 1 件ずつ 確認し、 頁・表と 原文の 抜粋を 記録しています。 内訳は、 原文に その 値が あるもの 531 件、 計算値 (半減期 × 倍数、 投与間隔からの 換算 など) 113 件、 クラス推奨の 値 59 件です。 2026-10 の 確認では、 ガイドライン 6 本・11 剤で 原文と 食い違う 値 (適用範囲の 外の 倍数の 当てはめ、 別の 薬の 数値の 混入、 逆向きの 期間の 取り違え、 ガイドラインに ない 外部の 値 など) が 見つかり、 修正しました。 続く 全件の 確認でも、 当日休薬を 0 日や 1 日と していた 値、 表の 読み違い、 原文に ない 値などが 見つかり、 修正しました。

このほか、 ブラウザで 画面を 操作する テストも 変更の たびに 実行しています。 監査の 際には、 原文と 薬の 名前だけを 別の AI に 与えて 数値を 独立に 抽出させ、 既存の データと 突き合わせることも あります。 食い違いが あれば、 作者が 原文で 確認して 判断します。

## 9. 変化の 検知と 反映

毎月、 次の 変化を 自動で 集めます (詳細は [README](../README.md#データを-正しく網羅的に-更新し続ける仕組み))。

| 対象 | 情報を 集める日 |
|---|---|
| 商品名・後発品 (KEGG 医薬品データベース) | 毎月 1 日 |
| 薬価基準 (厚生労働省) | 毎月 1 日 |
| 学会ガイドラインの Web ページ | 毎月 5 日 |
| ガイドライン PDF の 改訂 | 毎月 7 日 |
| PMDA 添付文書の 改訂 | 毎月 9 日 |
| PMDA 新規承認薬 (PMDA メディナビの メール) | 配信の たび |

- 監視対象の ガイドライン PDF (33 本) と 添付文書 PDF (118 件) を 公開元から 取得して 改訂を 検知します。 ガイドライン PDF は 内容の ハッシュ値が 違えば 本文を 比較し、 保存し直し だけ (本文が 同じ) は 改訂と しません。 添付文書は 改訂で URL が 変わっても、 新しい 版の URL を 探して 追跡します。 ガイドライン PDF の 改訂を 検知すると、 新しい 版で [3](#3-ガイドラインからの-抽出) の 抽出を 自動で 行い、 結果を 作者に 届けます。
- 集めた 変化は 月 1 回の 承認ページに まとめ、 作者が 項目ごとに 判断します。 **休薬日数を 自動で 書き換えることは しません**。
- このため、 **ガイドラインや 添付文書の 改訂から 反映まで 最大 3 か月程度 かかることが あります**。 データの 版と 更新日は [`v1/meta.json`](https://numero-uno-jpn.github.io/kyuyaku-data/v1/meta.json) で 確認できます。

## 10. 商品名・後発品名

- 商品名・後発品名は、 KEGG 医薬品データベースから 毎月 取得します (商品名 592 件・後発品名 329 件。 別名を 含め 1,151 の 名称で 検索できます)。
- 自動で 行うのは **追加の 提案だけ** です。 確定済みの 名称を 削除・格下げする 変化が あれば、 提案 そのものを 止めます。 機械が 見つけた 名称は、 人が 承認するまで 確定扱いに しません。
- 後発品名は 「〇〇錠 5mg「メーカー名」」 のように メーカー名を まとめて 記録します。
- 厚生労働省の 薬価基準 収載品目とも 毎月 照合し、 新規収載・名称変更などの 差分を 確認します。

## 11. 限界と 今後の 課題

- **一次資料に 日数が 見つからない 薬が あります。** `verified` の 出典が ない 薬は 10 剤 (リマプロスト、 オメガ3脂肪酸エチル、 シロリムス、 タモキシフェン、 バゼドキシフェン、 シルデナフィル、 タダラフィル、 バルデナフィル、 ユベラN、 リチウム) で、 一次資料に 周術期の 休薬日数の 記載が 見つからないもの、 英国の 実務資料 (UKCPA) だけが 根拠の もの などです。 これらの 値は 作者の 採用値で あり、 根拠の 読み方は 作者解釈 ([5.5](#55-根拠が-あいまいな-値の-扱い-作者解釈)) に 記録しています。 資料が 何も ない 薬は 日数を 空に しています。
- **日数が 明記されていない 値を 含みます。** `class`・`derived`・未分類の 値は、 ガイドラインに その 薬の 日数が 書かれているわけでは ありません ([5.2](#52-値の-出どころ-value_derivation))。
- **確認は 作者 1 人が 行っています。** AI と 自動の 検査で 誤りを 減らしていますが、 最終的な 確認は 作者 1 人に 依存しています。 誤りに 気づいた 場合は [誤りの報告](https://github.com/numero-uno-jpn/kyuyaku-data/issues/new?template=correction.md) から お知らせください。
- **反映までの 時間差が あります** ([9](#9-変化の-検知と-反映))。
- **自動で 改訂を 監視できない 資料が あります。** 公開元が 自動取得を 拒否する ACC/AHA 2024 (毎月 手動で 確認) と、 公開元の PDF が 特定できていない 添付文書 (バルデナフィル) です。
- **換算に 依存する 値が あります。** 時間で 書かれた 推奨を 日数に 切り上げる、 表の 「Week N」「Month N」 (最終投与から N 番目の 週・月に 手術) を N−1 週・か月と 読むなど、 原文の 表現を 日数に 置き換えた 値を 含みます。 換算の 根拠は 確認の 記録に 残しています ([8](#8-誤りを-入れない-自動の-検査))。
- **対象外の 情報が あります。** 薬物相互作用、 術後の 再開時期の 網羅的な 情報、 小児の 用量別の 扱いは 含みません。

今後、 新規承認薬の 追加、 利用者からの 報告に 基づく 改善、 抽出結果の 検査の 強化 (形式の 検査の 範囲の 拡大など) を 進める 予定です。
